## v1.2.0 — общая громкость и логотип Алисы

Готовые бинарники под Яндекс Станцию Мини 2 (32-битный ARM, glibc 2.30).

```sh
mkdir -p bin && tar xzf yandex-station-mini2-bin-armv7.tar.gz -C bin
STATION=192.168.1.94 scripts/bootstrap.sh --with-airplay
```

### Что внутри

| Файл | Зачем | Сборка |
|---|---|---|
| `dropbear`, `dbclient`, `dropbearkey` | SSH | musl, статический |
| `fastfetch` | баннер при входе | musl, статический |
| `shairport-sync` | AirPlay | glibc 2.28, libconfig/popt статически |
| `mixvol` | утилита ALSA-микшера: список контролов и `mixvol set "SPK Master" 128` | glibc 2.28 |

### Новое с прошлого релиза

- **`mixvol`** — без неё не работает связка громкости, раньше её в архиве не было.
- **Громкость AirPlay и Алисы связана.** Выяснилось, что Алиса и кнопки крутят
  контрол `Master`, который на звук не влияет; реальная громкость — `SPK Master`.
  `shairport` теперь пишет в `SPK Master`, а демон `volmirror` переносит туда же
  значение `Master`. Итог: громкость регулируется с Мака, голосом и кнопками.
- **Баннер с логотипом Алисы** (`#7A55FF`), плюс температура CPU в строке.
- **Исправлен `airplay-free.sh`**: PID брался пустым из-за ведущих пробелов в busybox `ps`,
  поэтому `mediad` не убивался и AirPlay получал «устройство занято».

### Убрано

`spotifyd` из архива убран: Spotify отказывает сторонним клиентам в аудиоключе
(`audio key error 0 1`), это свойство аккаунта, а не сборки. Подробности в
`docs/FINDINGS.md`, разделы 9–11.

Проверено на прошивке `0.369.1.50.4794659041.20261021.299`.
