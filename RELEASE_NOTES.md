## v1.3.0 — всё собранное в одном месте

Готовые armv7-бинарники для Яндекс Станции Мини 2 (32-битный ARM, glibc 2.30, ядро 4.9.68).

```sh
mkdir -p bin && tar xzf yandex-station-mini2-bin-armv7.tar.gz -C bin
STATION=192.168.1.94 scripts/bootstrap.sh --with-airplay
```

### Ассет 1: `yandex-station-mini2-bin-armv7.tar.gz`

| Файл | Зачем | Сборка | Состояние |
|---|---|---|---|
| `dropbear`, `dbclient`, `dropbearkey` | SSH | musl, статический | ✅ проверено на Мини 2 |
| `fastfetch` | баннер с логотипом Алисы | musl, статический | ✅ проверено |
| `shairport-sync` | AirPlay | glibc 2.28, libconfig/popt статически | ✅ проверено |
| `mixvol` | ALSA-микшер из командной строки | glibc 2.28 | ✅ проверено |
| `librespot` 0.8.0 | Spotify Connect | glibc 2.28, Rust | ⚠️ ставится и логинится, но играет только если ваш аккаунт не упирается в отказ аудиоключа |

### Ассет 2: `spotiya-armv7-linux-gnueabihf.tar.gz`

Отдельный проект для станций: Spotify Connect + голосовое управление + TUI, собран его автором.
Лицензия MIT, установщик внутри архива (`scripts/install.sh`). На Мини 2 проверялся автором.
Мы проверили: ставится, логинится, устройство видно в Spotify — но музыка не играет по той же
причине, что и у `librespot` (см. `docs/FINDINGS.md`, разделы 9–11).

### Чего в релизе нет и почему

**`bt-proxy`** — прокси D-Bus, который показывает Алисе плееры как Bluetooth-телефоны (это путь
к «Алиса, пауза» для AirPlay и Spotify). Не кладём готовый бинарник, потому что у проекта-источника
**нет лицензии**, а распространять чужой код без разрешения нельзя. Соберите сами:

```sh
make build-btproxy     # скачает исходники и соберёт локально
make install-btproxy
```
