# Справочник по железу Мини 2

Что внутри колонки, как разложены разделы и периферия. Нужно, чтобы не бегать по sysfs
наугад. Помечено, что проверено нами на живой колонке, а что взято из документации и
ещё требует проверки.

| Разъём наушников | есть, с детектом подключения |
| quasar | 3.21 |
| Температура | ~42 °C в простое, 55–57 °C под нагрузкой ✓ |

## Карта флеша

```
mtd0 "bootloader"  2 МБ
mtd1 "tpl"         2 МБ
mtd2 "boot"       10 МБ
mtd3 "system"    ~80 МБ  -> ubi0:rootfs (ubifs, RO)
mtd4 "nv"          1 МБ  -> /tee (vfat, RO)
mtd5 "bkupgrade" 105 МБ  -> ubi1 (RW) = /bkupgrade, и /data — симлинк на /bkupgrade/data
mtd6 "recovery"  ~50 МБ
```

Практические следствия, которые мы видели сами:

- корень по умолчанию **read-only**, перед записью нужен `mount -o remount,rw /` ✓;
- на корне ~10 МБ свободных, поэтому крупные бинарники (librespot 11 МБ) туда не влезают,
  а в `/bkupgrade` — 81 МБ ✓;
- dm-verity не включён, свои правки в rootfs живут до перепрошивки.

## Индикация

Оба дисплея — обычные LED в sysfs, пишутся из userspace от root.

```
/sys/class/leds/mini2:{red,green,blue}:ring{1..6}/brightness     # кольцо, 18 каналов
/sys/class/leds/mini2:white:clock{A..G}{1..4}/brightness         # часы, сегменты A-G × 4 разряда
/sys/class/leds/mini2:white:clock{DEGREE,MINUS,PLUS1..PLUS4}/brightness
```

Что мы выяснили сами (подробно — в [FINDINGS.md](FINDINGS.md)):

- кольцо в простое прошивка не перерисовывает, выставленный цвет держится ✓;
- LED-часы `maind --platformd` перерисовывает **быстрее 50 Гц** ✓, поэтому свою анимацию
  на цифрах удержать нельзя — только полная замена демона;
- штатная яркость цифр — `170`, максимум `255`.

Анимации прошивки лежат в формате `.led`. Для 6 зон формат нами **не проверен**:
количество hex-колонок в кадре должно соответствовать числу зон.

## Звук

```
card0 "AML-AUGESOUND"
  TDM-B-sy6045s-hifi     playback + capture
  PDM-dummy              микрофоны
```

Тракт: `TDM-B` → ЦАП ES8156 → усилитель SY6045S → динамик. Отдельный вход
`AML-AUGESOUND Headphones` — детект наушников.

Важное, что нашли сами: в микшере есть `Master`, `AUX DAC`, `SPK Master`, `SPK Ch1/2`,
и **на громкость влияет только `SPK Master`** ✓. Алиса и кнопки при этом крутят `Master`,
который к звуку не подключён. Как это обойти — см. [FINDINGS.md](FINDINGS.md), раздел 13.

## Вход

- `sar0_pad0` — касание корпуса (SAR-сенсор AW96103), приходит как `/dev/input/event0` ✓;
- `AML-AUGESOUND Headphones` — детект джека, `/dev/input/event1` ✓;
- отдельного `gpio-keys` нет.

## Освещённость

```
/sys/bus/iio/devices/iio:device0/in_intensity_input    # люксы, сейчас 0.37 ✓
```

Годится для ночника: порог по люксам плюс запись в кольцо.

## Что осталось непроверенным

- точный формат `.led` для 6 зон;
- карта регистров ES8156 и SY6045S (`i2cdump`, осторожно);
- можно ли задействовать USB OTG как хост на этой модели;
- реально ли поднять A2DP-источник (у нас не вышло, см. [BLUETOOTH.md](BLUETOOTH.md)).
