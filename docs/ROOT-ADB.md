# Как получить root ADB (шаг 0)

Этот репозиторий начинается с момента, когда на колонке **уже есть root по ADB**. Сам root
добывается отдельным инструментом — ниже краткая карта и грабли, которые мы собрали.

## Инструмент

[hu553in/yandex-station-root](https://github.com/hu553in/yandex-station-root) — переупаковка
[eQuasar](https://git.gay/iwakura/eQuasar). Тестировалось только на **Mini 2**.

Нужен компьютер в той же сети, который умеет слушать порты 80/443 (и 53 — для DNS-хелпера).

## Что происходит по шагам

1. **Поднимаем подмену**: локальный DNS отвечает адресом прокси на `quasar.yandex.net`,
   `quasar.yandex.ru`, `scbh.yandex.net`; на 80/443 работает прокси с сертификатом от
   промежуточного CA, которому доверяет прошивка.
2. **Сброс колонки** до заводских: питание off → зажать кнопку отключения микрофона →
   подать питание → отпустить на жёлтом.
3. **Привязка Wi-Fi** в приложении «Дом с Алисой». Колонка зарегистрируется и заберёт конфиг
   у прокси.
4. **Одно обновление**: с заводской прошивки (`0.18.1...factory`) активация не завершается.
   Прокси подсовывает манифест с версией **`0.369.1.46...299`** — ZIP качается с настоящего
   CDN Яндекса. После установки приходит конфиг с `adbd.remoteActivation: true`.
5. **Перезагрузка** — на `:5555` поднимается ADB.

## Грабли, на которые мы наступили

- **Окно доверия 1–2 минуты.** Колонка сама обновляет `/system/vendor/quasar/ca-certificates.crt`
  вскоре после выхода в сеть — после этого MITM перестаёт работать (`unknown ca`).
  См. [FINDINGS.md § 1](FINDINGS.md#1-почему-mitm-перестаёт-работать-через-пару-минут).
- **`.50` не доверяет цепочке.** Если колонка успела обновиться до последней версии, активация
  не пройдёт. Отсюда и трюк с оффером именно `.46`.
- **Не делайте DNS-подмену глобальной** на роутере: телефон с приложением ходит на те же домены
  и получит заглушечный конфиг → «нет списка устройств». Подменяйте только для MAC колонки.
- **Не давайте колонке обновиться во время процедуры** — иначе потеряете окно.
- **`/data/local/tmp` на колонке не существует** — установщик падает на `mktemp`. Лечится
  `adb shell mkdir -p /data/local/tmp`.
- **`/` обычно read-only** — перед записью `mount -o remount,rw /`.

## Проверка, что всё получилось

```sh
adb connect <ip>:5555
adb shell id        # uid=0(root)
```
